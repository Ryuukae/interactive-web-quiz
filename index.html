How do I format my TXT?

Easily build a quiz by typing your questions and answers as plain text. Use Q= for the Question, A= for the Correct Answer, and D= for a Distractor (wrong answer).

  • Keep Groups Together: The lines for a single question must touch. Do not put blank lines inside a question block. Separate new questions with a blank line.
  • Required Lines: Each question group must have exactly one Q, exactly one A, and anywhere from 1 to 6 D lines.
  • Strict Order: The lines must always follow this exact sequence: Question, Answer, then Distractor(s).
  • Case Insensitive: You can use uppercase or lowercase prefixes (e.g., Q= or q=).
  • Indentation: Each line is trimmed so you may use whatever indentation you prefer. 
q=Your question here?
a=Correct option
d=Incorrect option

Q=What is the default port for HTTPS?
A=443
D=80
D=21
D=22
D=8080

q=Which protocol is considered secure?
  a=HTTPS
    D=FTP
    d=HTTP
    D=TELNET

How do I format my JSON?

Your custom file must be a valid JSON array containing individual question objects. Each object must strictly adhere to the following schema:

  • Root Structure: The entire file must be wrapped in a single array [ ].
  • Question Property: Each object requires a "question" key with a string value representing the prompt.
  • Answers Array: Each object requires an "answers" key containing an array of the available choices.
  • Answer Objects: Inside the answers array, each choice must contain a "text" key (the answer string) and a strict boolean "correct" key (true or false without quotes). 
[
  {
    "question": "Your question here?",
    "answers": [
      { "text": "Correct option", "correct": true },
      { "text": "Incorrect option", "correct": false }
    ]
  },
  {
    "question": "What is the default port for HTTPS?",
    "answers": [
      { "text": "443", "correct": true },
      { "text": "80", "correct": false },
      { "text": "21", "correct": false },
      { "text": "22", "correct": false },
      { "text": "8080", "correct": false }
     ]
  },
  {
    "question": "Which protocol is considered secure?",
    "answers": [
      { "text": "FTP", "correct": false },
      { "text": "HTTP", "correct": false },
      { "text": "HTTPS", "correct": true },
      { "text": "TELNET", "correct": false }
    ]
  }
]
